# Tru-Line Seattle — GitHub Pages design demo

Dark cinematic **Option A** multi-page static demo for Doug Tate / Tru-Line Frame & Wheel (Seattle + Bellevue).

**Live shop (source of truth):** https://www.trulineseattle.com/

## Pages
- `index.html` — Home
- `services.html` — Services detail
- `locations.html` — Seattle + Bellevue
- `contact.html` — Contact + mailto booking form (demo-only)

## Notes
- Extra $0 static Pages demo — not the Payload CMS fork.
- Real logo, facility photos, people photos, copy, NAP, and emails from the live site dig.
- Contact form uses `mailto:` only (no backend).
- Design lock: dark cinematic Option A; no yellow CTAs; frost plates on photography.

## Local preview
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory .
```
